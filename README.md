# Trafalgar — landing page

Landing page estática de uma clínica de saúde virtual fictícia ("Trafalgar"), feita para praticar HTML e CSS.

## Estrutura

```
.
├── index.html     # página principal
├── css/
│   ├── reset.css  # reset de estilos do navegador
│   └── styles.css # estilos da página
└── images/        # logo, banner e ícones dos serviços
```

## Como rodar

Não precisa de build. Abra o `index.html` no navegador ou sirva a pasta:

```bash
python -m http.server 8000
```
